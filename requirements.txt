# Python tooling for development and CI (pip install -r requirements.txt).
# The versions are pinned so that the result of a lint is reproducible: two different versions would
# mean two different verdicts on one same file. Dependabot (pip ecosystem) keeps them up to date; it
# is ".github/dependabot.yml" that asks it to, and without that file nothing would move.
ansible-core==2.22.0
ansible-lint==26.11.0
yamllint==1.38.0

# Checks that every file carries a copyright line and an SPDX identifier, and that every identifier
# used has its text under "LICENSES/". Nothing else in this CI can see a file added without a header.
#
# It was deferred by #32, on the reasoning that a root "LICENSE" is enough while the repository is
# unpublished. #52 reopened it: headers applied with no checker go missing, and the files that lose
# them first are the ones nobody thinks of -- NOTICE, README.md, an example file -- while a tree
# held to "reuse lint" in CI stays whole. The difference is not discipline, it is this job.
reuse==6.3.0

# Read by ".github/scripts/check_LiteLLM_account_isolation.py". It is the only dependency of this
# check and of "check_required_checks.py" (named below), and it was bought knowingly: the
# line-by-line version of the check did not see a cross-account fallback written in block style --
# the very form any YAML serialiser produces. A guard that depends on the writing style of what it
# watches is not one, and a "pip install" step in a job costs less than a bypassed quota.
# ".github/scripts/check_required_checks.py" reads the workflows with it too, since it was already
# paid for, and "check_LiteLLM_model_drift.py" the model list; that one's weekly workflow installs
# this pin and the next one, each read from its line.
PyYAML==6.0.3

# The Python SDK that the modules of "community.docker" reach the Docker Engine API through. The role
# needs it on the MANAGED NODE (README, "Prérequis"); it is listed here because the "role run" jobs of
# ansible-ci.yml run the example playbook against their own interpreter, which is that node there.
# Pinned like the rest, so that a release of the SDK cannot turn those jobs red on a tree nobody touched.
docker==7.2.0

# Renders the model list for "check_LiteLLM_model_drift.py". Pinned here although ansible-core also
# brings Jinja2: the weekly drift workflow installs PyYAML and this line alone, without ansible-core,
# and reads the version from this line, so Dependabot moves it with the other pins and every job
# renders the model list with the same version.
Jinja2==3.1.6

# Checks that every file carries a copyright line and an SPDX identifier, and that every identifier
# used has its text under "LICENSES/". Nothing else in this CI can see a file added without a header.
#
# It was deferred by #32, on the reasoning that a root "LICENSE" is enough while the repository is
# unpublished. #52 reopened it for a reason the neighbouring repositories make concrete -- measured
# on 2026-09-06 rather than quoted from their documentation, which was a file behind:
#
#   * "Dell_iDRAC_fan_controller_Docker" applies headers with no checker. Twelve of its git-tracked
#     files carry none, among them NOTICE, README.md and .env.example. ("reuse lint" would report
#     eleven of those twelve: it does not ask LICENSE itself to carry a header.)
#   * "Homelab_Ansible_deployment" runs "reuse lint" in CI and reports 600 / 600.
#
# The difference between the two is not discipline, it is this job.
reuse==6.2.0

# Python tooling for development and CI (pip install -r requirements.txt).
# The versions are pinned so that the result of a lint is reproducible, and aligned with those of
# "Homelab_Ansible_deployment": the two repositories write the same YAML with the same conventions,
# and two different versions would mean two different verdicts on one same file. Dependabot (pip
# ecosystem) keeps them up to date; it is ".github/dependabot.yml" that asks it to, and without that
# file nothing would move.
#
# No "reuse" here: #32 defers "reuse lint" for as long as the repository is not published. The SPDX
# headers themselves ARE applied on every file -- that is what PR #31 does and it is the practice of
# the neighbouring repositories. They are therefore CHECKED by nobody for now, and that is already
# visible elsewhere: "Dell_iDRAC_fan_controller_Docker" applies headers with no checker at all and
# 12 of its files carry none.
ansible-core==2.19.11
ansible-lint==26.6.0
yamllint==1.38.0

# Checks that every file carries a copyright line and an SPDX identifier, and that every identifier
# used has its text under "LICENSES/". Nothing else in this CI can see a file added without a header.
#
# It was deferred by #32, on the reasoning that a root "LICENSE" is enough while the repository is
# unpublished. #52 reopened it for a reason the neighbouring repository makes concrete: SPDX headers
# have been the rule here since #31, verified by nobody -- and
# "Dell_iDRAC_fan_controller_Docker" does exactly that, with 12 of its files having quietly lost
# theirs. The difference between the two repositories is not discipline, it is this job.
reuse==6.2.0

# Read by ".github/scripts/check_LiteLLM_account_isolation.py". It is the only dependency these
# checks pay for, and it was bought knowingly: the line-by-line version of the check did not see a
# cross-account fallback written in block style -- the very form any YAML serialiser produces. A
# guard that depends on the writing style of what it watches is not one, and a "pip install" step in
# a job costs less than a bypassed quota.
PyYAML==6.0.3
